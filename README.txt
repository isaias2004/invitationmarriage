# Invitación de boda · The Barn

Landing page responsive hecha únicamente con HTML5, CSS3 y JavaScript.

## Estructura
- `index.html`
- `css/styles.css`
- `js/script.js`
- `assets/` → colocá acá las fotos de ustedes.

## Fotos
Los nombres esperados son:
- `nosotros-1.jpg`
- `nosotros-2.jpg`
- `nosotros-3.jpg`
- `nosotros-4.jpg`
- `nosotros-5.jpg`
- `nosotros-6.jpg`

Si una foto todavía no existe, la página usa una imagen de respaldo online para que el diseño siga viéndose completo.

## Personalización rápida
En `index.html` reemplazar:
- `[Nombre]`
- `Mayo de 2027`
- horario
- dress code
- texto de historia
- link de WhatsApp
- versículo, si quieren otro.

La dirección de Maps está configurada hacia The Barn Canning.
